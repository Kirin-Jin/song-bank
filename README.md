A personal project contributing to my church community for easier access to lyrics and chord of a song. The website pull a list of songs that have been sang at the sermon (from google sheets), and extract each songs from individual google docs (that retrieve from google sheets) to the database.  

For right now, this website is for Indonesia Community, so the default language is in indonesian, and the songs is indonesian songs.
It's still work in progress, as in the future there will be more changes coming up as in:
- Automate the update of an database 
- Automate cleaning and reconstructing the database
- Etc.
